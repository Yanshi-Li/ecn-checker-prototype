Minimum requirements to obtain an ECN (PCN) number
All field titles marked marked with a "*" must be completed to save an ECN (PCN) and reserve its number.  If the required field content is not known enter your best guess and review it later.

Identification section
This section is about identifying a change (concession) so that it can be reported on.

 

Note- Information like the creation date and the writer is automatically capture by the system.

 

Change (Concession) Notice Number

Automatically generated change (concession) ID (sequential unique identifier)
 

Name of Change (Concession)

A brief general description of the change (concession)
Avoid the use of special characters >, <, :, ", /, \, |, ? and *

 

Project

Drop down list used to make it clear to Procurement and others which project the ECN (PCN) effects.
Pick the Project.  The + button will allow more than one to be added.
 

Product Group

Drop down list
Pick the Product Group that the change (concession) effects.
 

Associated A3

Drop down list to record if there is a support A3.
Pick Yes or No
 

A3 Number

 

Enter the A3 number(s) used.
 

Change (Concession)  Details
Reason for Change (Concession)

A narrative stating why the Change (Concession) is being done in plain english so non techincal people can understand what is driving the need for the change.
E.g. ECN- "Cost Reduction" or "To improve Assembly"
E.g. PCN- "Stock shortage of 611933 Screw" 

Description of Change (Concession)

A written description of what the Change (Concession) is in plain english
Structure of description:
The first paragraph needs to be a description of the change (concession) in generally terms.
Subsequent paragraphs must cover each part of the change (concession) in sufficient detail to allow anyone to determine the history of the part and the reason for each change (concession) when they are looked at in the future.
